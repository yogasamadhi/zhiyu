# 织云商业平台交付验收记录

执行日期：2026-09-10。本记录对应 [架构规范](../architecture/ZHIYUN_CLOUD_COMMERCIAL_ARCHITECTURE.md) 和 [实施计划](../product/zhiyun-cloud-implementation-plan.md)。验收对象是本地工作区的 P0–P5 实现，没有执行公网生产部署。

## 交付范围

- Portal：独立 Next.js 应用，官网、价格、下载、账户安全、订单、订阅、积分、设备和桌面授权页面。
- Admin：独立 React 19 应用，TOTP 登录、角色权限、用户、价格发布、托管模型测试与费率版本、订单退款、积分调整、设备、管理员、模拟工具、任务与审计。
- Server：Bun/Hono API 与独立 Worker，Drizzle/PostgreSQL、Redis 限流回退、持久任务、身份、模拟支付、订阅、积分和 AI 网关。
- Electron：系统浏览器 PKCE、主进程加密凭证、设备身份、托管 AI 与 BYOK 明确切换，所有助手工具在本地执行。
- 工程：共享 UI/契约/客户端、OpenAPI 生成与漂移检查、依赖边界、独立开发命令、容器、HTTPS 路由、迁移、备份恢复与云端 CI。

非 AI 桌面功能和 BYOK 不需要订阅；订阅只提供托管 AI 和逐月积分。微信、支付宝的购买、签约、周期扣款、取消、退款均为模拟。测试未产生真实扣款，也未发送真实短信、邮件或消耗真实模型资源。

## 核心业务证据

### 身份与设备

验证了验证码失败计数提交、一次性消费、验证绑定冲突、密码重置撤销会话、用户间资源所有权、Origin/CSRF、用户与管理员身份隔离，以及管理员 MFA 必需和 TOTP 重放拒绝。

桌面协议覆盖 S256 PKCE、重定向绑定、授权码一次性使用、两设备上限、刷新凭证轮换与重放撤销、解绑立即拒绝托管访问。解绑后的同一设备必须重新完成授权，旧会话不能随设备重新绑定而复活。

### 模拟支付、订阅与积分

两种渠道分别验证了重复及乱序通知、成功后迟到失败、周期续费、未知状态查询和取消。另有专门用例验证关单后确认支付成功只履约一次、退款确认前保留权益、确认后撤销未消费积分并保留历史消费。

可注入时钟覆盖 1 月 31 日、闰年 2 月 29 日、年付逐月发放、不结转、提前续费不补充当月已耗尽额度、过期后的预占释放不恢复可消费积分。唯一约束和事务防止重复履约、重复发放与重复结算。

并发用例验证预占不透支；新增周期边界锁竞争用例在 Worker 持有积分周期锁、API 等待该锁时写入发放账本，确认外键检查不会与账户串行化锁发生死锁。人工补偿与审计记录在同一事务提交。

### AI 网关与恢复

模拟上游验证 SSE 文本与 function tool call 透传、多轮调用关联同一助手回合、每次调用独立请求 ID、重复 ID 不再次请求模型。Token 使用量来自服务端上游响应，客户端不能指定扣费数。

缺失或无效 usage、上游中断、调用后结果不明进入待核查；取消、客户端断开和第二应用实例恢复不会盲目重发模型调用。预占额度跨 Worker 恢复保留，核查后可带原因补偿释放。Redis 连接故障时健康状态显示降级、限流回退 PostgreSQL，账本继续保持正确。

### Web 与真实打包应用

浏览器流程从 Admin 配置/测试模型、发布价格开始，再由用户购买模拟套餐、提交重复通知、检查余额/订单、签约及取消、退出并验证另一浏览器无会话。公共页面在 390 和 1440 像素宽度检查无横向溢出，页面展示免费功能边界和模拟支付提示。

商业桌面测试启动磁盘上的 `.app` 并断言 `app.isPackaged`，通过独立浏览器完成 PKCE，验证加密凭证落盘、购买测试套餐、托管助手返回及数据库结算记录、显式切换 BYOK、设备解绑和退出。原有桌面回归还覆盖沙箱 Renderer、静态/动态采集、隔离登录、离线样例、草稿恢复和工作区可访问性。这里的 BYOK 验收确认模式切换与本地入口可用，没有使用真实用户 API Key 请求外部服务。

## 容器与备份恢复

三种交付镜像均完成本机构建与启动：Server、Portal、Admin。Server 镜像包含四个 Bun bundle 入口，无需完整开发依赖。使用相同镜像启动 Worker，并在 PostgreSQL 核对心跳。

- API 健康检查报告数据库和 Redis 可用。
- Portal/Admin HTTP 页面返回 200；Caddy 的本地 HTTPS 路由及 Admin 同源 API 返回正常响应。
- 本地 HTTPS 使用 Caddy 内部证书，冒烟请求以测试客户端跳过信任校验；这不等于公网证书或浏览器信任链已验收。
- 镜像内迁移命令再次运行成功，未重复创建迁移对象。
- 以 `NODE_ENV=production`、`CLOUD_MOCK_PAYMENTS=true` 启动实际 Server bundle 被拒绝，错误为 `Production refuses simulated payments`。
- 对 E2E 库执行自定义格式备份，恢复到新建 `zhiyun_cloud_restore_20260910_test` 库。恢复后核对：**2 条订单、2 条服务期、3 条账本记录、账本净额 9999、1 条已结算 AI 请求**。

备份不依赖 Redis；恢复演练没有覆盖日常开发库。完整操作方式见 [运行与交付手册](../../platform/deploy/README.md)。
