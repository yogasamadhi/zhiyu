# ZhiYun 1.0 验收基线

最后校准：2026-08-28

## 已取代的初始化决策

- Bun workspace 取代 pnpm workspace。
- TypeScript `packages/ai-runtime` 取代 Python、uv、FastAPI 与 PydanticAI sidecar。
- `/api/v1` 是唯一业务协议；不恢复旧 `/api` 路径。

## 1.0 发布门槛

- Desktop 与 Headless 共用 Contracts、Runtime、Client 和 UI。
- 静态、动态、JSON、列表详情、登录态和五种分页模式通过真实 E2E。
- RuleVersion、Dataset、增量变更、三种文件导出、Webhook 与外部 PostgreSQL 可用。
- 同一任务不得重叠；取消会终止网络和浏览器工作；崩溃恢复结果可审计。
- Desktop 安装包在没有 Bun、Node、Python、Docker、PostgreSQL 或 Redis 的干净系统运行。
- `bun run release:verify`、Web E2E、Desktop E2E 和目标平台安装 smoke 全部通过。

## 当前实现状态

### 已落地

- `CrawlPlanDefinition` 已统一列表、详情、Browser Actions、五种分页、去重和总量限制；旧 CSS/XPath/JSON 规则在 Repository 边界规范化。
- PostgreSQL 与 SQLite 已具有 Dataset、Change、Run Log/Request、Repair Proposal、Output、Delivery、Token、Schedule state 等 1.0 表与 forward-only migration。
- Run 成功状态、不可变快照、Dataset 投影和 Domain Event 在一个数据库事务中提交；双 Repository conformance 已覆盖提交回滚、Dataset 三模式、Run Diff、保留策略和调度状态。
- JSON API、HTTP、Playwright、HTTP→Browser 回退、Next/Page Number/Load More/Infinite Scroll、列表详情合并、详情 URL 去重、重试、总预算、响应体流式限额和 AbortSignal 已落地。
- 分析、页面点选、Rule Builder、版本 Diff/回滚、AI Schema/Rule/Extract/Repair/Explain 和人工确认链路已落地；Stagehand 保持显式 Experimental。
- Dataset 查询、搜索、字段过滤、Cursor Pagination、Run Diff、变更历史、CSV/JSON/JSONL/XLSX 流式导出已落地。
- Webhook HMAC/批处理/幂等/重试、外部 PostgreSQL Upsert/Append、Delivery 历史及只读 Scope Token Data API 已落地。
- Run 真取消、同任务互斥、最多 4 个 Local Crawl、queued 恢复、running interrupted、Cron 时区/misfire/pause/resume 已落地。
- RFC 7807、Trace ID、ETag/If-Match、Idempotency、会话 Token、SSE replay/realtime、Secret 脱敏和 SSRF/重定向检查已落地。
- Electron utility process、sandbox Renderer、一次性 nonce、generation 恢复、safeStorage、受控登录窗口、托盘、备份/恢复、诊断、随包 Chromium 和 Forge makers 已落地。
- 正式 tag Release workflow 要求 macOS 签名/公证及 Windows Authenticode 凭据；普通 CI 构建三种目标并执行源码 Electron E2E 和 packaged-app smoke。

### 本机已验证

- lint、Prettier、OpenAPI Client drift、TypeScript typecheck 和生产 build。
- 全量 Vitest、PostgreSQL/SQLite conformance、Runtime/Crawler security。
- 100 万条 SQLite Dataset 的 Cursor 查询和流式 CSV 性能用例。
- Web E2E：静态、Load More、Infinite Scroll。
- Desktop E2E：静态、动态、隔离受控登录。
- Packaged-app smoke：直接启动 `ZhiYun.app`，由包内 Chromium 完成动态采集。

测试数量以对应 CI run 的实际命令输出为准；发布记录应保存 CI 证据，而不是只引用本页。

## 发布前仍需完成的外部验收

- 在 GitHub macOS arm64、macOS x64、Windows x64 runner 上实际跑完新增 workflow，并保存 DMG、ZIP、Setup.exe 产物。
- 使用正式证书验证 macOS 签名/公证和 Windows Authenticode；当前本机只验证未签名测试包。
- 在三种目标的干净虚拟机安装、首次启动、动态采集、导出、退出及卸载；当前自动化验证的是 Forge packaged application，还不是安装器安装/卸载本身。
- 使用真实 OpenAI-compatible 与 Stagehand 配置做受控联调；无密钥回退、结构校验和 Mock 路径已经自动化覆盖。
- 发布前执行一次外部安全复核，重点检查 DNS 解析与建立连接之间的 rebinding 时间窗，以及企业代理/自定义 DNS 环境。

只有以上目标平台验收完成，才应把 1.0 Release Checklist 标记为可发布。

## 非目标

不实现账号体系、多租户、RBAC、分布式 Worker、验证码绕过、付费墙绕过、插件市场或自动更新。
