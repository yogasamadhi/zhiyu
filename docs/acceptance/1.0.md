# ZhiYun 1.0 验收基线

> 2026-09-10 更新：本文中的浏览器工作台、Headless 启动和独立发行内容属于历史方案，已由 [应用入口收敛决策](../adr/0011-desktop-cloud-apps.md) 替代；本地 Runtime、SQLite、插件与 Worker 的边界继续保留。

最后校准：2026-08-29

## 已锁定产品决策

- Level 2 Closed Internal Plugin Runtime + Local-first 模块化单体。
- TypeScript 产品控制面 + 同机受监督 Python 3.12 分析侧车。
- Product API `/api/v2`；Worker API `/worker/v1`；不兼容 `/api/v1`。
- 识别到明确 0.x Schema 时精确自动清空；未知 Schema 拒绝启动。
- 不开发旧数据备份、恢复、导入或转换工具。
- 不建设第三方插件、Marketplace、热加载、独立 Analytics 微服务或向量数据库。

## 源码验收状态

- Minimal Kernel、DAG/Profile/Graph Revision、贡献 staging、Effect rollback/cleanup 已落地。
- 正式 `desktop-studio`、`headless-server`、`safe`、`test`、`e2e` Profile 已登记。
- Legacy Plugin、全局 Repository、旧 SQLite/PostgreSQL storage、旧 Scheduler 和旧 migration chain 已从活动工作区删除。

- `/api/v2`、Runtime Graph/OpenAPI 双向校验、生成式 Product/Worker Client 已落地。
- Dataset Snapshot、NDJSON/Parquet、Artifact checksum/reuse 与路径安全已落地。
- 全部首发分析方法、资源预检、确定性抽样、Result provenance 与导出已落地。

## 性能与尺寸

参考机器为 8 CPU、16GB RAM、至少 30GB 临时磁盘：

- 100 万行 profiling/group aggregation/time trend 在 10 分钟内完成。
- TypeScript Runtime RSS 不因 Snapshot 线性增长超过 1GB。
- Worker RSS 默认不超过 4GB。
- 基础分析 10 分钟、高级分析 30 分钟、Corpus Build 60 分钟超时。
- 取消 2 秒内可见，10 秒内退出或 hard kill。
- Worker crash 后 30 秒内恢复或明确 degraded。
- Worker onedir 不超过 650MiB；Desktop unpacked 不超过 2.5GiB。

## 本机已验证

- TypeScript lint、format check、typecheck、build、Architecture dependency/catalog drift、Product/Worker OpenAPI Client drift 全部通过。
- 全量 Vitest：39 个测试文件、175 项通过；覆盖 Kernel/Effect、SQLite/PostgreSQL conformance、Runtime、Plugin、Job/Event、Snapshot、Analytics、Corpus 与安全边界。
- Python Worker：38 项 pytest/golden/property 测试通过，独立 Supervisor/Worker smoke 通过。
- Web E2E 4/4、未打包 Desktop E2E 3/3 通过。
- macOS arm64 Forge package 成功；真实打包应用 E2E 1/1 通过，覆盖内置 Chromium 动态采集、Dataset Snapshot、内置 PyInstaller Worker 和 `data.profile` 结果页面。
- 打包 Worker 启动器验证 onedir 候选必须是可执行文件，避免把同名资源目录作为进程启动目标；degraded 原因进入 Desktop diagnostics。
- macOS arm64 实测：Worker 源 onedir `526,896 KiB`（约 514.5 MiB），完整 App `1,558,484 KiB`（约 1.49 GiB），均低于 650 MiB / 2.5 GiB 门禁。
- Dependency audit 检查 887 个包后无 high 级未豁免漏洞；3 个仅构建期上游例外有独立说明和移除条件。
- License inventory 已生成 1,103 条 Node package 与 51 条 Python package 记录，并随 Desktop/Headless 发布资源装配。
