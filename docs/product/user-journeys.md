# 织云产品说明与用户路径

适用：Web / Desktop 共用工作台，产品与体验优化版本（2026-09）。

## 工作台结构

主导航依次为概览、采集任务、数据集、分析与报告、自动化、场景应用。设置、账号操作和语言切换位于导航底部；窄屏使用可收纳导航。职位雷达、内容趋势和语料工具从场景应用进入，也可以固定到导航。固定入口和表格偏好按持久化工作区标识、登录用户隔离。

概览根据已有数据提供开始采集、继续草稿、查看异常和最近结果。正在加载或未完成质量评估时不把未知值显示为零或正常。

## 首次采集：三步完成

1. **选择页面**：输入网址和希望得到的数据。可选择业务目标、专业模板、AI 辅助或内置商品样例。
2. **确认字段与预览**：设置记录容器、字段名称、类型和提取规则；支持真实浏览器点选。预览显示字段未匹配数量、空值比例、类型转换异常和前三条样本值，可以逐条切换样本并标记已检查。影响数据提取的修改会使预览失效；名称、运行计划和输出设置不会使已验证规则失效。
3. **保存运行**：填写任务名称、运行频率和输出目的地，选择保存或保存并运行。完成后进入任务、数据结果、导出、分析或定时更新。

草稿由当前实例保存，地址包含草稿标识。刷新可以恢复已保存内容；短时间连续编辑会合并自动保存。返回其他页面前会补存尚未发送的编辑，离开整个窗口时会提示尚未保存的内容。网络错误可以重试；版本冲突要求重新读取最新版本，不静默覆盖其他编辑。

AI 助手链接到同一份草稿，只能修改与生成规则有关的受限字段。模型设置页保留返回地址。尚未配置模型时仍可手动编辑和运行内置样例。旧 AI 会话在继续编辑时转换为统一草稿，历史消息和规则版本保留。

内置商品样例有明确标识，仅由已登记的示例执行器执行；无需外网和模型，不访问外部网站，不自动连接外部输出，也不计入体验指标。

字段质量只统计当前预览的最多十条记录，不代表全量数据质量。“缺失”表示字段选择器没有匹配到元素或属性；“空值比例”包含未匹配、空白及转换失败后产生的空值。旧预览没有结构化诊断时，缺失与类型异常显示未测量，需要重新预览。

列表规则建议检查至少三个不同样本，对照来源页面、记录容器与每个字段的规则和值。只匹配一条时检查是否误选整个页面或详情容器；疑似导航或广告记录需要缩小列表项选择器并重新预览。样本“已检查”标记只保留在当前预览界面，重新预览会清空。

列表与详情通过 URL 字段关联。预览会显示链接匹配数、详情记录匹配数和无法建立唯一关系的原因。多个链接或多个详情容器匹配时，先缩小对应选择器再预览；三步草稿提交会拒绝这些歧义关系。缺失链接、详情访问失败或达到预览请求上限也有对应提示。非法 CSS、XPath、JSONPath 和不存在的详情 URL 字段不能保存为可执行规则。

## 专业配置与已有任务

三步流程保留页面访问、浏览器操作、分页与详情、请求控制、数据更新、保存与输出等高级区域。技术模板参数、浏览器动作和完整结构化配置仍可编辑。已有任务使用同一草稿模型，提交后生成新规则版本。专业编辑入口继续提供规则比较、激活与回滚。

旧任务、运行、数据集、AI 会话、分析和语料链接继续可访问；专业编辑可通过原编辑地址加 `?professional=1` 进入。

任务列表可按名称或网址搜索、按状态筛选、排序、分页和选择多项。批量运行、暂停或恢复定时计划、删除逐项报告结果。部分失败可以先处理失败原因；删除不会自动重试。任务详情统一组织概览、数据、质量、分析、输出和运行历史。

从任务的“运行记录”进入某次运行，可以查看导航、页面动作、字段匹配、提取和 Dataset 写入步骤。字段按当次执行的规则版本标注；没有该版本信息时显示字段序号。页面访问失败提供新建重试运行入口，字段失效或空结果链接到规则编辑，超时和资源上限链接到请求控制，取消后可以新建运行。修改配置或重试不改写历史运行。

采集期间的“采集暂存”表示一批数据已接收，原 Dataset 仍可查看；“结果更新”完成后才显示本次运行的 Dataset 和 Snapshot。取消或最终失败会清理本次暂存，保留已有采集结果。

“导出诊断包”生成所选运行的 JSON，包含时间、规则版本、执行 Trace ID、步骤类型、计数、耗时和固定错误码；不包含页面内容、网址、选择器、请求头、Cookie、填表值或截图。最多保留最近 256 个步骤，导出的 JSON 不超过 64 KiB，超出时标明截断；浏览器下载完成后释放临时 Blob 地址，不另存服务端诊断包。历史运行或诊断暂不可用时，已有采集结果仍可查看。

“清理本次诊断”仅在运行结束后可用，删除该次运行的步骤诊断，保留采集记录、不可变 Snapshot、普通日志和其他运行的诊断。只读用户可查看和导出，清理与重试遵守工作区写入及运行权限。

## 确认和使用数据

数据集默认显示来源任务名、记录数、更新时间和质量状态。没有评估结果时显示“未评估”。

记录表的搜索、AND 筛选和排序作用于完整数据。支持标量等于、不等于、包含、数值或日期比较、为空和非空。改变条件会重新分页；同时展示数据集总量和匹配数量。列显隐独立保留。

导出菜单支持 CSV、JSON、XLSX，使用与列表一致的查询和可见字段。服务端在一致性读取中流式生成文件。Desktop 使用本地保存窗口，Web 下载文件。数据变更区可选择起止运行，统计覆盖全部差异，明细按页展示。

## 分析与报告

从数据集进入分析，选择数据版本；没有可用版本时创建版本，界面显示准备状态并持续查询。最新可用版本优先选择。

按数据质量、分类比较、时间变化、异常发现进入，也可浏览完整 18 方法目录。参数中的字段来自版本 schema；数值、日期和文本参数只提供兼容字段。后台继续执行最终参数校验。

分析任务提供进度、取消和重试。结果显示摘要、图表、数据表和导出，抽样与方法溯源可展开。分析服务不可用时，已有结果仍可读取和导出。

## 语料工作台

选择数据版本 → 选择正文与元数据字段 → 配置清洗、去重和分块 → 预览 → 构建并导出。

预览使用所选不可变版本前 20 行，执行与正式构建相同的清洗与分块逻辑，明确标记抽样范围。正式构建处理完整版本，完成后自动显示语料结果；结果页可按文件导出 Parquet、JSONL、清单及配置的其他输出。高级 Unicode、近似去重、语言和分块参数保留。

## 清洗数据与复用配方

在任务的“数据”页或数据集页进入“清洗与数据版本”。选择已准备好的输入版本；没有版本时，点击“从当前采集创建输入版本”。输入质量会显示字段类型、空值数量和比例、空白文本数量，以及有明确范围的 Facet。页面下方的“原始采集记录”继续显示采集内容。

按顺序添加去首尾空白、空值归一、数字或日期转换、拆分、合并、按字段去重步骤。支持选择多个字段、移动或删除步骤；新增的拆分或合并字段可用于后续步骤。“步骤参数”可查看精确空值标记、转换失败策略、分隔符和目标字段。最多 20 步，只有这些类型化操作可执行。数字使用十进制表示，日期接受 ISO 日期或时间；转换失败可置空并报告，或停止并保留输入。

点击“预览清洗”查看各步骤的质量、转换前后值、错误和删除行计数。预览是每个步骤输入的前 10 行，每行最多 25 个字段、文本最多 500 字符；重复行即使被删除，仍显示在该步预览中。错误样本最多 20 行。Facet 跟踪前 50 种不同值，默认展示最多 10 种；未跟踪次数、已跟踪但未展示次数与值截断都有标记，不能解释为完整值分布。

预览通过后填写名称并保存配方，再“应用配方并保存结果”。每步产生独立不可变版本，保存输入、参数、配方版本、各步输出和报告，原始 Parquet、Manifest 与采集记录不会改写。已有配方改动后保存为新版本；旧历史继续指向当时的版本。“复用已保存配方”可以把同一顺序应用到另一个兼容输入；字段缺失或类型变化会拒绝执行并提示检查版本和步骤。

在历史中点击“查看历史”恢复当时的报告与选择；“撤销一步”和“重做一步”切换已保存版本，撤销到步骤 0 就选中原始输入。选中的历史版本用于页面顶部“开始分析”，检查预览步骤的下拉框只改变报告视图。“复用此配方版本”可继续使用旧历史的不可变配方，即使配方已有更新。预览或应用期间可停止清洗；停止和失败不会改写源数据。

本功能在本地 Worker 执行，不需要 API Key 或模型。验收用例为 `desktop/e2e/cleaning.spec.ts`，确定输入/输出夹具为 `desktop/tooling/evaluations/cleaning-fixtures.json`；当前证据与实现边界见 [无需外部凭据优化执行记录](../verification/zhiyun-no-credentials-optimization.md)。

## 从问题开始分析与比较分支

从数据集或清洗历史的所选版本进入“开始分析”。在“你想了解什么？”选择分类差异、时间趋势、异常或字段关系，检查推荐字段与参数，再运行。缺少所需数值或时间字段时，先清洗类型或选择另一个版本；时间趋势也可以只按日期统计记录数量。所有计算在本地 Worker 中执行。

结果保存当时的输入版本、清洗配方版本、分析配方与参数。之后的数据采集或配方修改不会改写已有结果。结果页可以“编辑分支参数”，运行新分支后与原结果比较；不同方法或不兼容结果会提示原因。较大的表格和图表按页读取，图表无法加载或绘制时仍可查看表格、重试和导出。

四类问题、冻结输入、历史恢复、分支和图表回退的可运行本地样例为 `desktop/e2e/analysis-questions.spec.ts`。

## 条件监控与事件历史

在任务的质量页设置“字段值变化”“记录数量下降”或“空值比例上升”。可以选择阈值单位、连续异常次数、冷却与聚合时间；字段变化和空值条件支持包含/排除字段，排除优先。查看条件预览后保存。新条件默认连续 1 次、冷却 300 秒、聚合 3600 秒；已有策略保持原语义，只有保存后才改变配置。

成功运行后的监控事件保留首次、最近异常、计划通知次数和关联运行记录。事件和运行历史支持上一页/下一页，点击运行编号可追溯实际采集。通知被系统拒绝或不可用时，事件仍可查；计划通知次数不代表系统已经送达。关闭事件保留历史，之后再次异常仍会记录。

定时任务继续使用现有的 `skip` 和 `run-once` 错过策略：恢复时跳过已错过的执行，或补跑一次。当前本地验收覆盖睡眠、唤醒与离线，不发送 Webhook、邮件或短信。完整样例为 `desktop/e2e/monitoring.spec.ts`。

## 专业编辑器中的规则历史与修复

专业编辑器的规则历史卡片支持比较版本与回滚。回滚会创建新版本，原版本保持不变。点击“AI 修复建议”后，在界面内填写失败现象并生成建议；取消或空输入不会创建提案。

先查看 Diff，再测试当前网页。只有实际测试通过的提案才能确认应用；应用创建新 RuleVersion，拒绝保留当前规则。生成建议需要已配置的模型或明确的 Mock 验证环境，查看和回滚已有规则不依赖模型。可运行的 Mock 样例为 `desktop/e2e/task-rule-history.spec.ts`。

## Cloud 完整历史查询

账户中心的订单、积分流水、用量、设备和会话，以及后台的记录列表，使用服务端筛选和游标分页。输入搜索、适用状态或时间范围并应用，再查看下一页；后台部分列表还支持用户编号。切换账户、资源或筛选会从第一页开始，清除筛选可恢复完整历史。加载错误时使用重试，不把错误当成没有记录。

列表不再只查询最近 200 条。后端仍按登录身份、所属用户和员工角色控制访问；分页不增加权限。隔离测试样例为 `platform/server/tests/lists.test.ts` 与 `platform/portal/e2e/lists.spec.ts`，实际购买使用模拟支付。

上述路径的命令、样例数据与无外部凭据边界见 [本地优化验证指南](../examples/no-credentials-workflows.md)。

## 自动化与场景

自动化分为计划任务、数据同步、消息通知和 API 访问。新增连接时打开配置对话框，按连接类型呈现所需字段。采集状态和输出状态分别显示；采集成功但投递失败时可以仅重试输出。

职位雷达以匹配职位和跟进状态为主页面。首次仅填写档案名称和职位关键词，其他条件后补。文件导入依次选择来源、文件、字段映射、确认和结果，成功后进入职位列表。未安装同步适配器时明确显示“文件导入 / 原站跳转”，本轮未增加招聘平台采集适配器。

内容趋势沿用现有来源能力，保留上次成功数据并区分更新中、过期、失败和重试。

## 设置与本地指标

设置分为通用、AI 模型、连接与凭据、数据与存储、账号安全、诊断。已有采集引擎、Worker、凭据保护和权限机制继续生效。

管理员可在数据与存储中查看、关闭和清除本地体验指标。仅保存事件类型、时间、匿名关联、耗时和结果类别，默认保留 90 天，不上传外部统计服务，不保存网址、提示词、字段值、采集内容或凭据。示例行为排除。

首次完成率 = 有首次成功运行的创建流程 / 已开始的创建流程；首次结果耗时使用中位数。结果使用率统计已成功采集的任务中发生导出、分析或同步的比例。7 天复用率只使用已满 7 天观察期的任务。没有数据或观察期不足显示“—”。

## 织云助手新增路径（2026-09-10）

首页保留任务概览，并提供网页、想法、学习和样例入口。助手可在没有网址或任务时开始；已有内容通过 `/assistant?conversation={id}` 恢复。帮助方式可以切换，原目标、资源和学习进度保留。

字段建议先预览，再用操作卡保存或保存运行。任务、运行、草稿和数据集页面可就地求助；普通页面跳转不会自动切换操作目标。采集或输出失败后可在原会话继续诊断。历史预览仅代表当时样本，配置改变后要重新预览。

无模型时提供明确标识的固定引导和离线教程。完整验收路径与当前证据见 [助手验收记录](assistant-acceptance.md)。
