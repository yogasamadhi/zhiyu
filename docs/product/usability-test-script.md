# 代表性用户测试脚本与指标基线

本文件是可执行的招募与测试方案。自动化测试和内部操作不构成真实用户研究结论，未填写的数据不得用样例或开发者操作替代。

## 招募和环境

招募 5–8 名运营、研究或内容岗位的代表性用户，其中至少 3 名没有编写采集规则的经验。分别覆盖 Web 和 Desktop，中英文与至少一名键盘操作用户。每次 40–50 分钟，主持人仅在用户请求帮助时提示，记录帮助发生的步骤。

准备独立实例，包含内置样例、一个有历史结果的数据集、一次失败采集、一次采集成功但输出失败的运行。AI 分别准备未配置与可用两种状态。先取得参与者对观察笔记的同意；不要求他们提供真实密码、生产凭据或敏感业务数据。

## 任务脚本

| 任务       | 给参与者的目标                                    | 观察与通过标准                                                 |
| ---------- | ------------------------------------------------- | -------------------------------------------------------------- |
| 首次采集   | 不连接模型，尝试产品并得到一份商品表              | 找到样例；完成三步；理解样例标识；查看 6 条结果并导出          |
| 草稿恢复   | 改字段名称，离开页面再继续                        | 找回草稿；知道哪些变更需要重新预览；不重复建任务               |
| AI 辅助    | 在原草稿中配置模型并返回                          | 返回同一草稿；手动高级设置保留；能理解冲突提示                 |
| 查找数据   | 找出指定价格范围的数据并只导出两个字段            | 使用完整数据筛选；正确区分总量与匹配数；导出和表格一致         |
| 分析       | 找出数据缺失情况或数值分布                        | 通过名称选择数据与版本；无需寻找内部 ID；理解摘要与下一步      |
| 语料       | 从文本字段构建可导出的语料                        | 完成选择、配置、预览、构建；理解抽样与全量区别                 |
| 自动化     | 处理一次输出失败                                  | 能区分采集与输出；选择只重试输出，避免重复采集                 |
| 职位雷达   | 创建最小档案并导入文件，收藏一个职位              | 两个必填项即可开始；理解映射与错误行；导入后找到职位并更新状态 |
| 窄屏和键盘 | 在 360px 下找到语言、账号和设置，打开再关闭对话框 | 导航可收纳；焦点恢复；无需横向滚动整个页面                     |
| 指标控制   | 关闭并清除本地体验指标                            | 理解本地存储和排除样例；明确清除影响，不误删业务数据           |

每项记录是否独立完成、耗时、错误/回退次数、是否需要提示、参与者原话及主要障碍。结尾询问最困惑的一步、结果是否可信、下次使用意愿；不要以诱导问题要求认可改版。

## 指标基线

真实用户基线尚未采集。首次完成率、首次可用结果耗时中位数、结果使用率和 7 天复用率暂不填写数值。7 天复用率至少等待完整观察期；样例任务与测试实例不纳入真实产品转化报告。报告同时列出观察样本量、观察时间、失败原因分布与缺失数据，避免只展示百分比。

建议先记录首批用户一周基线，再依据观察中反复出现的障碍设定下一轮目标。内部自动化验收记录见 `experience-implementation.md`。

## 织云助手观察任务

招募 5–8 名代表性参与者，其中至少 3 名没有采集经验。测试者先给目标，不提前说明按钮、字段或采集术语。记录独立完成、开始/结束时间、提示次数、回退动作和结果准确性，不在测试前设定或虚构完成率。

1. 只说一个模糊的数据需求，观察参与者能否找到来源、解释一行含义、选择字段、预览并保存。
2. 提供一个可验证的网页和指定字段，观察参与者是否检查样本空值，能否纠正字段并重新预览。
3. 完成点选及分页教程后，独立重做一次；观察其能否说明第一页和总范围的区别。
4. 使用受控失败任务，观察参与者能否打开就地求助、区分采集失败与输出失败、通过卡片恢复。
5. 任务完成后留在原会话提问，再导出数据；刷新与切换页面后检查其对当前帮助对象的理解。

分别记录真实网站、打包样例、教学和纯问答，不合并为采集完成率。参与者反馈和真实模型表现由人工填写；自动化测试结果不能替代本记录。
