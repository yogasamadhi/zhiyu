# 织云产品路线图（2026 Q4）

适用：桌面工作台体验改造之后的下一阶段。本文只记录**尚未实施**的产品方向，以及决定优先级的依据；已落地的界面改造见 [用户路径](user-journeys.md)。

## 定位：研究与语料工作台

主场景选定为 **A：研究 / 语料工作台**。目标用户是需要从公开网页持续获取结构化数据，并整理成分析结果或训练、评测语料的研究者、分析师和小团队。

叙事主线：

> 在本机把网页变成可追溯的数据版本，再一路清洗、分析、导出成语料，全程不上传数据。

据此调整的取舍：

- 导航中，语料工作台与采集、数据集、分析并列，构成一条主路径；职位雷达、内容趋势继续作为场景应用。
- 对外宣传以“本地优先、可追溯版本、无需 API Key 也能完成闭环”为差异点，不和通用 RPA 或云爬虫平台比拼规模。
- 新功能先回答一个问题：它是否缩短了“网址 → 可用语料或分析结论”的路径。

## 度量：北极星指标与匿名遥测

当前只有本地体验指标（[设置与本地指标](user-journeys.md#设置与本地指标)），不出本机，因此无法验证真实用户的转化。

- **北极星指标**：每周完成“采集 → 分析或语料导出”闭环的活跃工作区数。
- **漏斗**：安装 → 首次运行样例 → 创建第一个真实任务 → 首次成功运行 → 首次分析或语料构建 → 7 天内复用。
- **可选匿名遥测**：
  - 默认关闭，首次启动时用一句话说明用途并提供开关；
  - 只上报事件类型、耗时分桶与结果类别，与本地指标同口径；
  - 不上报网址、提示词、字段值、采集内容和凭据。
- **前置条件**：先招募 5 到 8 位目标用户，按 [可用性测试脚本](usability-test-script.md) 走一遍新的核心路径，再决定遥测范围。

## 本地 MCP 服务

把采集、数据集查询、分析和语料构建以 MCP 工具的形式开放给本机的 AI 客户端。

- 只监听本机回环地址，使用每次启动重新生成的令牌，权限沿用工作区角色；
- 首批工具：
  - 列出任务和数据集；
  - 读取数据集分页；
  - 触发运行并等待结果；
  - 运行内置分析方法；
  - 构建语料并返回清单；
- 写操作（运行、构建）在桌面端弹出确认，或者要求在设置中预先授权；
- 与现有 `/api/v2` 共用同一套服务契约，不新增独立后端。

## 云端定时与监控（付费版）

桌面端只有在设备开机时才能执行定时任务。付费版把**已验证的规则**托管到云端按计划运行：

- 规则与凭据加密上传，并且必须由用户逐个任务明确授权；
- 运行结果回传到本地数据集，形成同样的不可变版本；
- 字段失效和数量下降的监控在云端执行，通过已配置的消息通道告警；
- 依赖现有 Cloud 账户、积分与订单体系，计费按运行次数和请求量计算。

## 合并两套 AI 助手

目前同时存在“织云助手”（全局，负责教学、诊断和操作卡）和“采集助手”（规则生成）。两者入口、会话历史和能力边界都有重叠。

- 合并成一个助手。按当前页面上下文自动切换能力集，会话历史统一；
- 保留“只能修改受限字段”和“先预览再保存”的约束；
- 旧会话链接重定向到合并后的会话。

## 个人模式

单人使用时，成员、邀请、审计和角色等概念没有意义，反而增加理解成本。

- 首次启动默认进入个人模式，隐藏成员、邀请和审计入口；
- 需要协作时在设置中切换到团队模式，数据不迁移、不丢失；
- 权限检查仍在服务端执行，个人模式只改变界面呈现。

## 国内生态输出

在现有的 Webhook、文件和数据库输出之外，补齐国内常用的协作和存储渠道：

- 消息通知：飞书、钉钉、企业微信的机器人与应用消息；
- 数据同步：飞书多维表格、阿里云 OSS；
- 沿用现有输出连接的凭据保护与投递重试，各渠道单独标注状态。

## 定价分档（草案）

| 档位   | 面向       | 包含                                                       |
| ------ | ---------- | ---------------------------------------------------------- |
| 免费   | 个人试用   | 本地采集、清洗、分析、语料全部能力；本地定时；自带模型 Key |
| 专业版 | 个人研究者 | 云端定时与监控额度、托管模型积分、国内生态输出             |
| 团队版 | 小团队     | 团队模式、成员与审计、共享云端额度、优先支持               |

本地能力不设功能墙，付费点放在“离开本机仍能持续运行”和“团队协作”上。

## 暂不做

- 第三方插件市场、公共 SDK、运行期热加载（与 [ADR 0007](../adr/0007-level2-closed-runtime.md) 一致）；
- 通用 RPA 和桌面自动化；
- 绕过登录、验证码或访问控制的采集能力。
